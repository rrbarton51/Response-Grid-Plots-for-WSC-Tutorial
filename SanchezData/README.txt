README for SanchezData Folder
This folder contains a .csv file df_solver_results_gen.csv  kindly shared by Susan Sanchez with
  data used in the paper "Data Farming the Parameters of Simulation-Optimization Solvers" by
  Shashaani, Eckman and Sanchez published in ACM TOMACS 2024. It is used by the RGP codes for
  the 2026 WSC tutorial on Response Grid Plots by Russell Barton.
